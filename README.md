# うちのコタロット：今日の1枚

23枚からランダムに1枚引き、カード名・ひとことメッセージとプチヒントを表示するテンプレートです。特別カードは「羅針盤」です。正位置・逆位置は毎回それぞれ50%の確率で決まり、逆位置は画像を180度回転して表示します。引き直すと、同じカードや向きが出ることもあります。

## ファイル構成

- `index.html`：画面のデザインと1枚引きの処理
- `cards-data.js`：うちのコの名前、23枚の画像ファイル名・カード名・メッセージ、表紙とリンクの設定
- `cards/`：カード画像23枚
- `my.html`・`love.html`：既存の誕生日診断・相性診断（今回の変更対象外）

## お客様ごとの差し替え

1. このフォルダを複製します。開発用の `.git` は配布・公開には不要です。
2. `cards/` の画像を、お客様の23枚に入れ替えます。同じファイル名なら画像だけの交換で使えます。
3. `cards-data.js` の各カードの `image`（画像ファイル名）、`name`（カード名）、`message`（正位置メッセージ）、`reversedMessage`（逆位置メッセージ）を編集します。画像名を変更した場合は `image` も合わせます。カード名に「・正位置」「・逆位置」を書く必要はありません。表示時に自動で追加します。
4. 必要に応じて `petName` を変更します。例：`"モモ"` → 「モモの今日の1枚」。空文字 `""` なら「今日の1枚」と表示します。
5. 複製先の `index.html` を開き、画像・カード名・文章とボタンの動作を確認します。

カード情報の例：

```js
{
  "image": "00_The_Fool.png",
  "name": "愚者",
  "message": "今日は軽くはじめて大丈夫😊\n完璧じゃなくても、まず一歩でOK🌈",
  "reversedMessage": "今日は勢いだけで進まず、ちょっと確認してみよう😊 急がなくても大丈夫だよ🌿"
}
```

`image` には `cards/` を含めず、ファイル名だけを書きます。大文字・小文字と拡張子も画像と一致させてください。カードは23件を維持し、画像名の重複を避けてください。

`message` の `\n` は画面で改行になります。文字列を囲む `"`、項目間の `,`、括弧は残してください。文章中に半角のダブルクォートを入れる場合は `\"` と書きます。ファイルはUTF-8で保存してください。

## 表紙とリンク

次の設定も `cards-data.js` にあります。今回のチャッピー＆サリー版では従来の設定を維持しています。

- `heroImage`：表紙画像。お客様用に変更する場合は、例えば `cards/cover.png` を指定できます（23枚のカードとは別の画像です）。
- `menuUrl`：「しあわせメニューに戻る」の移動先
- `readingUrl`：以前の案内ブロック用の設定です。案内ブロックを削除したため、現在の画面では使用しません。

カード画像はすべて手元の `cards/` を読み込みます。現在の表紙だけは外部URLなので、表示にインターネット接続が必要です。お客様用に複製する際は、表紙とリンクもご確認ください。

## 起動・公開

ライブラリのインストールやビルドは不要です。`index.html` をブラウザで直接開けます。カードデータは通常の `<script>` で読み込み、JSON取得用のサーバーは使いません。

ブラウザに古いカードデータが残らないよう、HTMLでは `cards-data.js?v=2` を読み込みます。今後カードデータを更新するときは、HTMLの `v=2` を `v=3` などに増やしてから、HTMLとデータファイルを一緒に公開してください。

公開するときは `index.html`・`cards-data.js`・`cards/` を同じ構成でアップロードしてください。既存の診断も使う場合は `my.html`・`love.html` も含めてください。

配色・レイアウト、1枚引き・引き直し・戻る、15種類のプチヒントの内容と抽選方法は既存版を維持しています。
